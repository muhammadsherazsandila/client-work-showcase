## 💡 What I Built

### Architecture

```
┌───────────────────────────────────────────────────┐
│                    FRONTEND                        │
│    Next.js + TypeScript + Tailwind CSS             │
│         + Framer Motion + shadcn/ui                │
│                                                    │
│  ┌──────────┐  ┌──────────┐  ┌─────────────────┐  │
│  │ Services │  │Portfolio │  │      Blog       │  │
│  │ Showcase │  │ Gallery  │  │   (SEO/Tips)    │  │
│  └──────────┘  └──────────┘  └─────────────────┘  │
│                                                    │
│  ┌──────────┐  ┌──────────┐  ┌─────────────────┐  │
│  │ About &  │  │ Booking  │  │   Animations    │  │
│  │  Team    │  │  System  │  │   & Motion      │  │
│  └──────────┘  └──────────┘  └─────────────────┘  │
│                                                    │
│         Deployed on Vercel (Custom Domain)         │
└───────────────────────────────────────────────────┘
```

### Key Features Built

1. **Dynamic Hero & Landing**
   - Animated hero section with Framer Motion
   - Smooth scroll-triggered animations throughout the page
   - Premium micro-interactions on hover and scroll

2. **Service Pages**
   - **Web Development:** Custom websites, e-commerce, full-stack applications
   - **Graphic Design:** Branding, visual identity, logo design, social media creatives
   - **Digital Marketing:** SEO, PPC campaigns, performance marketing strategies

3. **Portfolio Gallery**
   - Showcase of 20+ delivered projects with categories
   - Project cards with hover effects and technology tags
   - Client projects: Zarandam, Pureganic Bliss, Fintac, Khushi Riders, Trendora, Roomify
   - Branding projects: AS Arts, Blogora, Social Media campaigns

4. **Blog & Content**
   - Technical articles on web development best practices
   - SEO strategy guides for businesses
   - Digital marketing tips and insights
   - Content-driven SEO for organic traffic growth

5. **Consultation Booking**
   - 30-minute consultation scheduling system
   - Contact form with project details capture
   - WhatsApp integration for quick inquiries

6. **Design System**
   - Custom component library using shadcn/ui as foundation
   - Consistent typography, spacing, and color system
   - Dark theme with accent colors reflecting brand identity
   - Fully responsive across all device sizes

## 🛠️ Tech Stack

| Layer | Technology | Why |
|-------|-----------|-----|
| **Framework** | Next.js, TypeScript | SSR/SSG for performance and SEO |
| **Styling** | Tailwind CSS | Rapid styling with design consistency |
| **Components** | shadcn/ui | Accessible, customizable component primitives |
| **Animations** | Framer Motion | Premium, smooth animations matching agency positioning |
| **Deployment** | Vercel | Seamless CI/CD, edge caching, custom domain |
