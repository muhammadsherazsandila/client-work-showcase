## 💰 Signature Architecture: Zero-Cost E-Commerce Stack

I designed a **zero-cost infrastructure pattern** for local Pakistani brands. Clients only pay for their domain name (~$12/year) while getting a full-featured e-commerce platform:

| Service | Provider | Cost |
|---------|----------|------|
| Frontend Hosting | Vercel (Free Tier) | $0 |
| Backend API | Render (Free Tier) | $0 |
| Database | MongoDB Atlas (Free — 500MB) | $0 |
| Image CDN | Cloudinary (Free Tier) | $0 |
| Email Notifications | EmailJS (Free — 200/month) | $0 |
| **Total Monthly** | | **$0** |

> 💡 Each client gets a **custom admin dashboard** to manage their own products, orders, and content — no Shopify or third-party CMS fees.

## 🛍️ Zarandam — Premium Fashion E-Commerce

> **Client:** Zarandam Fashion Brand, Lahore, Pakistan  
> **Live:** [zarandam.com](https://zarandam.com)  
> **Status:** ✅ Live & Active  

📖 **[Read Full Case Study →](./case-studies/zarandam.md)**

### The Challenge
Zarandam, a premium Pakistani women's fashion brand, needed a modern e-commerce platform — but could not afford traditional hosting costs.

### What I Built
- Full e-commerce platform with product catalog, cart, checkout, and order management
- **Custom admin dashboard** for client to manage products, orders, and inventory
- Multi-category browsing (embroidered suits, western wear, formal dresses)
- COD and mobile wallet payment support with free shipping over PKR 6,000
- Image optimization via Cloudinary CDN, email notifications via EmailJS
- **Zero-cost hosting** — Next.js on Vercel, Express.js on Render, MongoDB Atlas free tier

### Tech Stack
`Next.js` · `TypeScript` · `Tailwind CSS` · `Express.js` · `MongoDB` · `Mongoose` · `Cloudinary` · `EmailJS`
